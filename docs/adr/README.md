# Architecture Decision Records (ADR)

Short notes on irreversible, non-obvious architectural choices.

## First file

In [/explore](../skills/explore/SKILL.md) mode, create this catalog and ADR
files **lazily** — only when all criteria in
[ADR-FORMAT.md](../ai/ADR-FORMAT.md) apply (costly rollback, non-obvious,
real trade-off).

Until then this README may be the only file here.

## Naming
